# 🎀 Oops!

### 퍼스널 컬러, 피부 타입을 아직도 모르고 계세요?
### 📸 사진 한 장으로 1분 만에 확인해 보세요!

<br/>

## 📖 About

> 오프라인 매장에서만 받을 수 있던 진단을, 이제 온라인에서 간편하게.

**Oops!** 는 오프라인 매장을 직접 방문해야만 받을 수 있었던 **퍼스널 컬러 및 피부 타입 진단**을
온라인에서도 쉽고 간편하게 이용할 수 있도록 기획된 서비스입니다.

- 📷 **사진 한 장**으로 퍼스널 컬러와 피부 타입을 분석
- 💡 분석 결과 기반 **맞춤형 화장품 정보** 제공
- ⏰ **시간과 장소의 제약 없이** 누구나 손쉽게 진단
